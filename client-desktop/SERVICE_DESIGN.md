# 桌面启动与后台连接

- 登录自启动只启动托盘界面，不需要管理员权限；可独立开关。
- 免登录连接由 launchd / Windows SCM 管理独立的 Rust supervisor，继续复用 Go client 边车。
- 系统服务与桌面窗口只有一个连接管理者。启用服务后，窗口通过带随机密钥的本机 RPC 管理它；关闭窗口不会停止服务。
- 本机 RPC 只监听 loopback，密钥和端口文件只允许配置所有者、服务账号和管理员读取。窗口与服务复用现有 core 的状态类型，不复制网络协议或伪造在线状态。
- 启用时先停止桌面边车，再迁移配置和 SQLite 凭证。停用时先停止系统服务，再把配置迁回桌面。切换失败需要恢复原管理者。
- macOS daemon 以配置所有者 UID 运行；Windows 使用 LocalService。机器级程序文件由管理员安装，连接数据单独授权。
- 后台二进制位于系统级固定目录，不依赖登录后才能解锁的用户目录。FileVault / BitLocker 的启动磁盘解锁之前不支持运行。
- 桌面更新包同时包含 UI、Go client 和服务宿主。启用系统服务时，更新先经系统授权更新后台二进制，再执行桌面整包替换；后台更新失败时恢复原二进制。
- 安装、停用和服务升级只由用户在设置中明确触发，并使用系统原生管理员授权。测试不修改开发者电脑的真实启动项。
- 应用卸载拥有完整的服务清理流程，不依赖用户提前关闭启动开关。Windows 系统卸载入口先执行清理，再交给 Velopack 删除应用；快速卸载回调只执行无界面的停用保护，不能在其 30 秒时限内等待管理员交互。
- macOS 提供应用内卸载入口和随包独立卸载工具。直接删除或移走应用时，后台暂停连接；安装包原子替换恢复后可以重连。直接拖废纸篓不能自动获得管理员授权，必须明确区分“连接已停”与“系统组件已清理”。
- 完整卸载先迁出仍在使用的服务配置，移除系统注册和后台目录，保留用户数据；清理失败不得继续删除应用。删除其他用户或其他数据目录的服务必须拒绝。
